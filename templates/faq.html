Frequently Asked Questions

Everything you need to know about CryptoVault's security, wallets, and transfers.

How are crypto balances stored and verified?

Every wallet balance is denominated in a specific cryptocurrency and tracked with high precision (8 decimal places) in the relational MySQL schema. When a user sends funds, an atomic database transaction deducts the sender's balance and credits the receiver's balance simultaneously.

What are the network fees for transactions?

Network fees are calculated based on the respective blockchain network rules (e.g. 0.00005 BTC, 0.0008 ETH, 0.00002 SOL). The fee is clearly displayed and deducted at confirmation time.

Can I claim free testnet cryptocurrency?

Yes! Each wallet has a built-in Developer Faucet button. Simply visit your wallet details page and click Claim Faucet Airdrop to receive instant testnet crypto for testing transfers.

How is user authentication secured?

Passwords are never stored in plaintext. They are salted and hashed using BCrypt at write time. Spring Security filter chains validate every protected route and enforce CSRF token verification on all form submissions.
